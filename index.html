Scattertown Hermes

HARS Google Access connects a privately operated Hermes assistant to Google Drive, Google Docs, and Google Sheets for Scattertown’s document and spreadsheet workflows. HARS stands for Holdings Analysis & Returns System.

What the integration does

With the account owner’s authorization, the assistant can read, create, and update documents, spreadsheets, and files used for analysis and administrative work. This is a private-use integration, not a public sign-up service.

Permissions and boundaries

The integration requests read/write access to Drive, Docs, and Sheets. Google’s authorization can cover accessible files across the connected account. The operator restricts routine work to an approved folder through assistant policy; that restriction is not a Google-enforced folder-only permission. Deletion and sharing changes require separate operator approval.

This informational website does not provide access to the assistant, Google files, or private infrastructure. Read the privacy policy for data handling details.
