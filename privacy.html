Privacy policy

Effective October 18, 2026. This policy describes the private-use Scattertown Hermes integration, also identified as HARS Google Access, operated by Scattertown Holdings.

Information accessed

After Google authorization, the integration can access the connected account’s email address for identity checks, file metadata, document text, spreadsheet values, and other file content needed for authorized tasks. It can create and update files. It stores OAuth credentials to maintain authorized access without requiring the Google account password.

Purpose and access limits

Google data is used to perform owner-directed document, spreadsheet, analysis, and administrative tasks. Routine use is restricted by operator policy to an approved folder and its descendants, although the granted Google permissions are broader. Gmail, Contacts, and Calendar access are not requested by this integration.

AI providers and memory services

Content retrieved for a task may be included in prompts sent to configured external AI providers. Conversations, extracts, or derived information may also be processed by configured memory services. Processing is therefore not exclusively local. Provider-specific storage, retention, and data-use terms depend on the services and account settings in use. Before sending Google user data to a provider or memory service, the operator must verify that its terms and settings permit processing consistent with this policy and Google’s applicable requirements. Unverified services must not receive Google user data.

Storage and security

Original files remain in Google unless the operator explicitly changes them. Working copies, generated outputs, conversation history, logs, and derived memory may be stored on operator-controlled systems and by configured processing services. OAuth credentials are stored separately from this public website with restricted local file permissions. These measures do not constitute a guarantee of absolute security.

Retention and deletion

There is no fixed automatic deletion period specified for this integration. Records may remain until the operator deletes them or a configured retention process removes them. Deleting a Google file does not necessarily remove copies in conversation history, working files, memory, logs, or backups. Deletion requests should identify the relevant records so those locations and applicable provider processes can be reviewed; immediate deletion from all backups cannot be promised.

Revoking Google access

The account owner can revoke access through Google Account connections. Revocation stops future authorized API access but does not itself delete previously stored copies or generated outputs. Contact the operator separately about deletion.

Data-use commitments

The operator does not sell Google user data, use it for advertising, or intentionally supply it to train general-purpose AI models. Transfers to service providers are limited to authorized functionality and must comply with the Google API Services User Data Policy, including its Limited Use requirements. This policy establishes operating requirements; it is not a claim that Google has verified or endorsed the application.

This website

These informational pages contain no application login, analytics scripts, advertising, or forms. This website is hosted on GitHub Pages. GitHub and may process ordinary request and security information under its own privacy statement. Google files and OAuth credentials are not part of this website.

Contact and updates

Privacy contact: scattertown@gmail.com. Material changes to the integration’s data handling should be reflected in this policy.
